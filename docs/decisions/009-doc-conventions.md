# 009: Documentation conventions

- Date: 2026-08-23
- Status: accepted
- Source: product owner

- Docs folders (decisions, proposals, research, issues, stories) keep
  numbered files (`001-name.md`) and a `README.md` used as the index.
- Every artifact type has a template in docs/templates/ and files follow it.
- Proposals and decisions are separate folders sharing a similar shape.
  Proposals carry a status (proposed, accepted, rejected); accepting a
  proposal produces or updates a decision record citing it. Files never
  move between folders.
- Keep prose short everywhere; templates state per-type length limits.
