# 011: Git conventions

- Date: 2026-08-23
- Status: accepted
- Source: product owner

- Conventional commits everywhere (`feat:`, `fix:`, `docs:`, `test:`,
  `chore:`, `refactor:`, with scopes like `feat(core):` once crates exist).
- Semantic versioning for the crates; the workspace starts at 0.1.0.
- Commit and push often; small commits at natural boundaries.
